# Book Library

**The books behind the wiki.** Every GTM discipline here traces to a handful of source books. This library names them and distills each one to the ideas that still drive decisions. The goal is not a reading list. The goal is the usable core: what each book says that changes how you run GTM.

Each entry follows the same rule: **the book in one line, then the ideas that earned their place in the wiki.** Sources are cross-linked to the wiki pages they feed.

## How to use this library

1. **Pick the discipline, not the shelf.** Sales reps read the sales page. Marketers read the marketing page. Founders read both.
2. **Read the one-liners first.** Each book is compressed to its operating ideas. If one line disagrees with your playbook, open the book.
3. **Follow the cross-links.** Every entry points to the wiki page that applies the idea. The book is the source. The wiki page is the operating manual.
