# Skills

A **skill** is a reusable, trigger-driven instruction set a person or an agent runs to do one GTM job well. It is the difference between knowing outbound works and having a working outbound motion. This section ships the skills as runnable artifacts, not descriptions of them.

gtmskills.com catalogs skills as prose authored by named practitioners. This section matches that breadth and adds the moat they lack: each skill carries the template, the worked math on a named base, and the agentic SOP that runs it. The reference `MEDDPICC` flow is the quality bar every page here is measured against.

## How a skill page is built

Every page follows the same anatomy so you can run it cold:

1. **Trigger**: the conditions that say "run this now," stated first so you can skip what does not apply.
2. **Definition**: what the skill is, in one concrete sentence.
3. **Why it matters**: the stakes, named and dated where a figure exists.
4. **The mechanics**: the steps broken into parts, each taught to the point you can act.
5. **The artifact**: the template, grid, or checklist shown in the page, not summarized.
6. **Worked example**: the skill run on a named base with the arithmetic shown.
7. **Failure modes**: how the skill breaks and the fix for each.
8. **Agentic layer**: the SOP or prompt an agent uses to run the skill, and where a human must stay in the loop.

## Skills in this section

- [Prospecting](./prospecting): build account, contact, or both lists from ICP fit, enrichment, and signals. Trigger: a target list, ICP-fit prospects, or decision-makers.
- [Outbound](./outbound): the cold email and call motion that turns a list into meetings. Trigger: a list and a value hypothesis ready to send.
- [Messaging and copywriting](./messaging): turn who you sell to into words that work. The three-layer model and the email frameworks that structure the copy. Trigger: about to write something a buyer reads.
- [Signals](./signals): read buying intent from profile views, job changes, and funding. Trigger: a signal fires and you must decide fast or let it cool.
- [ABM](./abm): run few high-value accounts as a coordinated program. Trigger: a named account list and deal economics that justify the spend.
- [Pricing](./pricing): set and defend price as a GTM motion. Trigger: a pricing decision, a discount request, or a packaging change.
- [SEO](./seo): earn compounding organic reach. Trigger: a content or search program with a horizon longer than one quarter.
- [Ads](./ads): buy pipeline on paid platforms. Trigger: budget to deploy and a payback target to hold.
- [RevOps](./revops): run the data, tooling, and forecasting spine. Trigger: a reporting, attribution, or forecast gap.

## How to use this section

1. **Start from the trigger.** Most failures come from running a skill that does not fit the situation, not from running it badly.
2. **Run the artifact, do not read it.** Each template is built to be filled, not admired.
3. **Pair each skill with its foundation.** Outbound needs the [GTM Strategy Framework](../foundations/gtm-strategy-framework) and [ICP definition](../foundations/icp-definition). Pricing needs [revenue architecture](../foundations/revenue-architecture). Read them together.
4. **Hand repeatable parts to an agent.** The agentic layer on each page is the part a model can run; the judgment calls stay with you.
