# Playbooks

**Playbooks** are step-by-step execution guides. Each one assumes you have the foundations in place and are ready to run. They describe *how* to do the work, not just what the work is.

- [Inbound Content Engine](./inbound-content-engine): build a content engine that turns customer problems into search-visible assets, from hub-and-spoke production to distribution and measurement.
- [Outbound from Zero](./outbound-from-zero): standing up outbound from scratch.
- [Customer Onboarding](./customer-onboarding): getting new customers to first value and renewal.
