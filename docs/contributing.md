# Contributing

The GTM Wiki is open source and community-driven. High-signal
contributions are welcome.

## What makes a good contribution

- **First-principles, not tactics-of-the-week.** Explain *why* something
  works, not just the current hack.
- **Operator-tested.** If you've run it, say so. Concrete numbers beat theory.
- **Company- and stage-agnostic.** Frameworks should adapt to any model.

## How to contribute

1. Fork the repo on [GitHub](https://github.com/leroyoakley777/GTM-Wiki).
2. Add or edit a page under `docs/` with proper frontmatter (`sidebar_position`, `title`).
3. Cross-link related pages with relative links.
4. Open a PR with a short description of what you added and why.

See the repo's root `CONTRIBUTING.md` for full formatting conventions.
