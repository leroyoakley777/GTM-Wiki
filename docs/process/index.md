# Process

Process covers the intake system. It turns a raw dump into a classified item with a home. The section documents the capture rules, the classification step, and the routing that follows.

## Pages

- [Intake Capture](/docs/process/intake-capture): how every dump is captured, classified, and turned into an actionable task.

The capture rule this section runs on:

```
dump -> classify -> file to a home -> task with an owner
```
